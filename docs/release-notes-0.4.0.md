# Animal Crossing Multiplayer — Beta 0.4.0

An **unofficial fan project**. Not affiliated with or endorsed by Nintendo. No game data is included: you need **your own legally obtained disc image** of *Animal Crossing* (USA, GAFE01_00). Windows 10/11 64-bit with OpenGL 3.3.

## Install
1. Download `ACGC-PC-Multiplayer-0.4.0-win64-first-install.zip` and unzip it into a normal writable folder.
2. Put your disc image in the `rom` folder.
3. Run `ACLauncher.exe`.

## Update
Run `ACLauncher.exe`. It offers new versions and installs them (your `save`, `servers` and settings are never touched). Back up `save` before updating. If you run a dedicated server, update the server folder too (`Start Server.bat` can do it when `check_updates = 1`). Everyone should update: 0.3.0 players see big outdoor furniture as a leaf, and a 0.3.0 host cannot read the new outdoor furniture save.

## Changelog
- Furniture outdoors: big pieces (2x1 and 2x2) can be placed now, including dressers and wardrobes. Grab, push, pull and rotate them like indoors. Dressers and other storage open outdoors from the front, for residents and guests. Placing and picking up play the normal animations.
- Hand-over animations: Tom Nook's work mode, and villagers giving and taking items, now show for everyone.
- Roommates: a guest can ask to move in by talking to the house's gyroid (in its normal dialogue). The owner accepts, denies or removes roommates there. Roommates share house editing, the dresser storage and the music box, and start at the house door when they join.
- Shop: Tom Nook (and Timmy and Tommy) follow the nearest player, the same on every screen.
- The version number is shown on the title screen.
