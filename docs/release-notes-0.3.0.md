# Animal Crossing Multiplayer — Beta 0.3.0

Update to Beta 0.2.1. This is an unofficial fan project, not affiliated with or endorsed by Nintendo, and it is still a beta: keep backups of your `save\` and `servers\` folders before playing and before every update. Most of what is new in this release was verified by automated tests (real game processes driven by scripts, and scripted test clients against a real host), **not yet by a person playing it**; see "Known limitations and what was not verified" below.

## What you need
Windows 10/11 (64-bit), a GPU/driver with OpenGL 3.3 core profile, and **your own legally obtained disc image** of *Animal Crossing* (USA, GAFE01_00) in the `rom\` folder. The packages contain no game data and nothing downloads any.

## Installing and updating
- **Existing installation:** start `ACLauncher.exe`; it offers 0.3.0 and installs it after you say yes (SHA-256 checked, previous program files kept in `.update\backup-<version>`, rolled back on any problem). Only `AnimalCrossing.exe`, `SDL2.dll`, `shaders\`, `licenses\` and the notes change; `rom\`, `save\`, `servers\`, `settings.ini`, `keybindings.ini`, `server_config.ini` and logs are never touched.
- **Server owners: update the server folder too.** With `check_updates = 1` in `server_config.ini`, `Start Server.bat` offers the update when the server starts (answer **Y**); or start `ACLauncher.exe` in that folder once. Players should update as well: most new features need 0.3.0 on both sides.
- **New install:** unzip `ACGC-PC-Multiplayer-0.3.0-win64-first-install.zip` into a writable folder, put your disc image in `rom\`, start `ACLauncher.exe`.
- **Nothing updates the launcher or the server starter.** They did not change since 0.1.1, so a 0.1.1 / 0.2.x installation needs nothing else.
- **One-time step for existing 0.1.0 installations** (only for the server's startup update check; the Dedicated server console improvements, the startup update check and "Host and play on the same PC" came with 0.1.1): open the first-install zip and copy only `ACLauncher.exe`, `Start Server.bat`, `server_starter.ps1` and `SERVER_SETUP.txt` over yours. **Never copy `server_config.ini`, `settings.ini`, `rom\`, `save\` or `servers\`.**

### New files and settings
- A 0.3.0 host writes, next to its town (`servers\<id>\` on a dedicated server, `save\mp\` on a game that hosts): `outdoor_furniture.dat` (furniture placed outdoors), `ops.ini` (the operator list) and `mutes.ini` (the chat mute list). `shop_upgrade.ini`, `museum_donors.dat` and `dresser_store.dat` are unchanged from 0.2.x.
- New `settings.ini` keys (all default on, `0` turns one off): `[Network]` `chat`, `menu_world_live`, `bulk_sell`, `npc_fallback`, `npc_relay`, `outdoor_furniture_place`, `outdoor_furniture_leaf_drop`, plus the safety ceilings `outdoor_furniture_max_town = 512` and `outdoor_furniture_max_acre = 128`; `[Gameplay]` `emotes`. New `keybindings.ini` keys: `Chat` (T), `Emote` (F), `Pad_Emote` (D-pad Up); the Controls > Keybindings menu lists Tool Wheel, Chat and Emote Wheel.

## What changed since 0.2.1

### Server and town
- **The day rolls over on a running host.** A host that stays up past midnight now runs the game's own new-day work in one short same-position town reload at a safe moment: villagers moving in and out, special and weekly events, the morning mail, and the 6 AM growth of trees, flowers and weeds. Weather, the Stalk Market and the shop line-up already renewed while running. Dedicated console: `day` shows the state, `day roll now` stops waiting for players in "soft" buildings. Host switch `AC_MP_DAY_ROLL=0`.
- **Shared event NPCs.** Redd, Saharah, Wendell, Gracie and the Wisp now go through the host: two players can no longer buy the same one-of-a-kind piece from Redd, Wendell's and Gracie's one-per-player gifts are counted for the whole town, and returning spirits to the Wisp is one host transaction. Host switch `AC_MP_EVENT_NPC=0`.
- **Villagers no longer freeze far from the host.** On a dedicated server the host only simulates villagers near its own (parked) observer, so villagers elsewhere stood still and could not be pushed. Now a client runs a villager itself when the host's stream is silent, the host relays that villager to the other players (message 99), players who do not run it can push it too, a stuck conversation hold ends after 120 s, and villagers no longer walk towards the invisible observer. Console: `npc`, `npc free <slot>`. Switches: `npc_fallback` / `AC_MP_NPC_FALLBACK=0`, `npc_relay` / `AC_MP_NPC_RELAY=0`, `AC_MP_NPC_PUSH_FIX=0`.
- **Outdoor furniture.** Residents can PLACE one-tile furniture outdoors (the real model, rotated and solid: the inventory menu offers Grab / Place / Drop / Quit; in front of a placed piece A rotates it, B picks it up). Residents, operators and the host's own player can pick up or rotate placed pieces; guests cannot. Dropping furniture as a leaf works as in the original game. Host settings above; switch `AC_MP_OUTDOOR_FURNITURE=0`.
- **Operators and new console commands.** `op` / `deop` / `ops` (stored by identity, not by name), `furniture list | remove | clear`, `mute` / `unmute` / `mutes`, `say <text>` and `chat on|off`.
- **Nook's shop building is synced when you join.** A player whose own save still had the old shop building now sees the town's current one (one black-fade reload after the arrival train, never during it). Switch `AC_MP_SHOP_JOIN_SYNC=0`.

### For players
- **Text chat:** press **T**, type, **Enter** sends (Esc cancels). The line appears as a bubble above your head for everyone in the same place and in the chat log. On a server without chat the key says "Chat is not available on this server". Settings `chat`, switch `AC_MP_CHAT=0`.
- **Emote wheel:** hold **F** or **D-pad Up**, point, release: Hooray, Shocked, Surprised, Pray, Phew, Boo!, Twirl, Exercise, with the game's own marks and sounds, shown to the other players. Setting `[Gameplay] emotes`, switch `AC_EMOTES=0`.
- **Nook's sell basket:** "I want to sell" opens a basket screen: add mixed items, see the total, press the Sell button to sell them in one go; B cancels and the basket never remembers its contents. Setting `bulk_sell`, switch `AC_MP_BULK_SELL=0`.
- **The world keeps running behind menus** (inventory, map, Esc menu) in multiplayer: other players keep walking, villagers move, tree shakes and dropped fruit animate, the ground refreshes. Setting `menu_world_live`, switch `AC_MP_MENU_WORLD=0`.
- **More of the other players' animations:** 22 more actions play their real animation (pushing / pulling furniture, sitting, mail jumps, the pitfall sequence and more), furniture, bed and talk reactions (message 96), another player's bobber and the fish or bug they caught (message 97), blinking, balloons and pinwheels in hand, the swollen face after a bee sting, and the clothes-change animation (`PC_PUPPET_CLOTH_ANIM=0` turns that one off).
- **Fixes:** the notice board's page animation is no longer slow at high frame rates; a client with full pockets gets the normal "pockets full" refusal instead of a pretend pickup; several lost-and-found claims in one police-box visit work; short waits (such as the dresser's first open) use real seconds, so they no longer fail at uncapped frame rates; the F3 speed toggle was removed.

## Playing with other versions
The network protocol number stays 8, so 0.2.x and 0.3.0 games can connect. New since 0.2.1, added in place: messages 96-101, transaction kinds 21 and 22, town services 9 and 10, refusal reasons 50-61. Older games ignore what they do not know. **The new features need 0.3.0 on the host AND the client.**
- **A 0.2.1 player on a 0.3.0 host:** plays as before without the new features: no chat or emotes, other players' new animations are not shown, furniture placed outdoors looks like a dropped leaf, and the 0.2.1 behaviours remain on that player's side (villagers far from the host may still stand still for that player, event NPC purchases of that player stay local, the shop building can stay stale on that player's screen). A 0.2.1 guest cannot pick up a placed piece; a 0.2.1 resident can (it is returned as an item).
- **A 0.3.0 player on a 0.2.1 host:** the new features are simply not offered: the chat key says "Chat is not available on this server", Redd, Wendell, Gracie and the Wisp's return politely decline (Saharah trades as in 0.2.1), furniture can only be dropped as a leaf, and no new transaction is ever sent to the old host. Emotes play on your own screen; the old host does not pass the emote on, so other players see at most a plain pose.
- How this was checked: by reading the code of both versions (a 0.2.1 game ignores message ids above 92 and town services above 8; a 0.3.0 client sends transaction kinds 21 and 22 only to a host that announced them), by tests with scripted clients, and by one run of a 0.3.0 client against the real released 0.2.1 host (see the release evidence).

## Known limitations and what was not verified
- **Not verified by a person:** almost everything in "What changed": how the outdoor furniture, the emotes, the chat bubbles, the sell basket and the new animations look and feel; the day rollover through a real midnight (the tests move the clock) and a real villager moving in or out during it; Redd / Saharah / Wendell / Gracie / the Wisp through their real dialogues (tests drive the same client functions); villagers far from the host on a live server; the emote wheel with a real controller; chat with an IME. Also not verified: a real-ROM playthrough by a person, a clean-machine install and real public (internet) multiplayer.
- Outdoor furniture: one-tile pieces only, no sitting / lights / music / storage, villagers do not path around pieces, not on the island.
- Custom-design umbrellas are not shown on other players. Chat has no inline IME composition and no gamepad keyboard; characters the game font lacks become `?`.
- When a client runs a far villager, the villager's random choices come from that client, so it can behave differently from the host's own villagers.
- Still not shared: Joan, Katrina, Jingle and the fireworks stall; the island / Kapp'n; the fishing tournament and bug-off. The gyroid desync report is still not reproduced.
- The executables are unsigned, so Windows SmartScreen / antivirus may warn; the checksum detects corruption, not tampering. Some diagnostic environment variables are still read; they do nothing unless set. The test-hook mechanism is compiled out of this build.
- **Legal status (not cleared, unchanged):** the executable is built from a public decompilation and contains compiled code and data tables derived from the original game and from SDK headers carrying SGI/Nintendo copyright notices; supplying your own disc image does not settle the licensing of that compiled code.
