# Animal Crossing Multiplayer — Beta 0.3.0

An **unofficial fan project**. Not affiliated with or endorsed by Nintendo. No game data is included: you need **your own legally obtained disc image** of *Animal Crossing* (USA, GAFE01_00). Windows 10/11 64-bit with OpenGL 3.3.

## Install
1. Download `ACGC-PC-Multiplayer-0.3.0-win64-first-install.zip` and unzip it into a normal writable folder.
2. Put your disc image in the `rom` folder.
3. Run `ACLauncher.exe`.

## Update
Run `ACLauncher.exe`. It offers new versions and installs them (your `save`, `servers` and settings are never touched). Back up `save` before updating. If you run a dedicated server, update the server folder too (`Start Server.bat` can do it when `check_updates = 1`).

## Changelog
- Chat: press `T`, type, press Enter. A bubble shows above you and a short log appears in the corner. Operators can `mute` and `say`.
- Emote wheel: hold `F` (or D-pad Up) and pick one of 8 emotes. Tool wheel, Chat and Emote keys can be rebound in Controls.
- Sell to Tom Nook with a new basket screen: mix items, press Sell, confirm the total.
- Place furniture outdoors (residents). The operator list (`op` / `deop`) controls pickups and cleanup.
- The world keeps moving behind menus, including tree shakes and drops.
- The server rolls the new day while it keeps running (events, villagers moving, mail, field growth).
- Redd, Saharah, Wendell, Gracie and the Wisp are now shared between players.
- Far-away villagers no longer freeze, and anyone can push them.
- More animations for other players: pushing, pitfalls, sitting, bed, talking, fishing, clothes changes, and more.
- Shop building matches the host's when you join.
- Fixes: notice board is fast again, full pockets refuse pickups properly, the police lost and found lets you take several items, the dresser opens the new screen the first time, F3 turbo removed.
