# Animal Crossing Multiplayer — Beta 0.1.0

An **unofficial fan project**. Not affiliated with or endorsed by Nintendo. No game data is included: you need **your own legally obtained disc image** of *Animal Crossing* (USA, GAFE01_00). Windows 10/11 64-bit with OpenGL 3.3.

## Install
1. Download `ACGC-PC-Multiplayer-0.1.0-win64-first-install.zip` and unzip it into a normal writable folder.
2. Put your disc image in the `rom` folder.
3. Run `ACLauncher.exe`.

## Update
This is the first release. Later versions are offered by `ACLauncher.exe`. Back up `save` before every update.

## Changelog
- First public beta.
- Host and join multiplayer, with residents and guests. The host runs the world: items, digging, planting, shops and Nook, Gulliver and K.K. Slider, fish and bugs.
- Dedicated server with its own console and an easy start (`Start Server.bat`, `server_config.ini`).
- `ACLauncher.exe` checks GitHub for new releases and updates safely.
- Fixed: first-time character creation no longer disconnects during Rover's intro. Rover's "iiiiiiiiii" line is gone. Porter no longer offers trips to other villages.
