# Animal Crossing Multiplayer — Beta 0.4.1

An **unofficial fan project**. Not affiliated with or endorsed by Nintendo. No game data is included: you need **your own legally obtained disc image** of *Animal Crossing* (USA, GAFE01_00). Windows 10/11 64-bit with OpenGL 3.3.

## Install
1. Download `ACGC-PC-Multiplayer-0.4.1-win64-first-install.zip` and unzip it into a normal writable folder.
2. Put your disc image in the `rom` folder.
3. Run `ACLauncher.exe`.

## Update
Run `ACLauncher.exe`. It offers new versions and installs them (your `save`, `servers` and settings are never touched). Back up `save` before updating. If you run a dedicated server, update the server folder too (`Start Server.bat` can do it when `check_updates = 1`). Everyone should update: 0.4.0 players can still join a 0.4.1 host, but they do not get the new work mode or the synced train.

## Changelog
- Tom Nook's work mode, reworked:
  - Talk to Nook and pick "Give me a job" or "Check job".
  - Nook asks if you brought the item. Say No and he tells you to take your time, or makes it urgent with extra bells.
  - "Quit job" takes the parcel back.
  - Deliveries to a villager finish on their own when you hand the item over, and the villager's give animation plays while they talk.
  - Villagers give a tip of 50 to 300 bells for a delivery, more the better friends you are.
  - Much more variety in the items you fetch and deliver (not mostly stationery any more).
- Arrival train, synced: everyone sees the same train and Porter. A second guest steps off after the first one. If you join while the train is leaving, a new train comes for you and everyone sees it.
